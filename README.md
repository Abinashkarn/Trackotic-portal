# Track0tic QR — wireframe review

Static, clickable export of the Track0tic QR system wireframes (admin, tenant portal, field app, patient PDF).

Open `index.html` (GitHub Pages) and click through. `support.js` is a small runtime that renders the `.dc.html` screens; no build step.

Handoff documents: `Track0tic_QR_Handoff_Index.pdf`, `Track0tic_QR_Flowcharts.pdf`.
