One rule for every device type. HUB, PRO, LITE, LOCKBOX all resolve to the same device page; scanning a device does exactly one thing — bind passports to it. Type-specific behaviour (lockbox opening, diagnostics bench) is extra sections on that page, not a different flow.
Typed code is always offered next to the camera (8-char short code under every passport QR). Binds made that way are tagged TYPED and shown as such to staff; they are still valid binds.
